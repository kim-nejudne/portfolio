Only the owner edits `docs/SPEC.md`. Gaps and conflicts found while building go here.

## Open spec questions

Each has a recommended answer. Until the owner says otherwise, a feature that hits one uses the recommendation and moves it to "Decisions made".

6. **Undo after a reopen.** Resolved in F20 as recommended; see "Decisions made".
7. **Scoreboard overlay never hides itself.** Resolved in F13 as recommended; see "Decisions made".
8. **`host:prev` onto an answered question.** Resolved in F13 as recommended; see "Decisions made".
9. **Who counts as "eligible" after a wrong answer.** Resolved in F19 as recommended; see "Decisions made".
10. **Kicking the current buzz winner.** Resolved in F20 as recommended; see "Decisions made".
11. **Missing limits.** Resolved in F02 as recommended; see "Decisions made".
12. **Server memory.** Images live in memory at up to 50 MB per room, and room creation allows 10 rooms per IP per hour. A small always-on host can run out. *Recommend:* add a global image cap (for example 500 MB). Over the cap, refuse new uploads with a clear error. *F02:* `GLOBAL_IMAGES_MAX_BYTES` is 500 MB. *F30:* enforced; an upload past it gets 507.
13. **`fx buzz` payload `gaps`.** Resolved in F02 as recommended; see "Decisions made".
14. **Pairing from a Screen without the token.** Resolved in F10 as recommended; see "Decisions made".
15. **"Monorepo layout" vs "one TypeScript project".** Resolved in F01 as recommended; see "Decisions made".
16. **RTT before the first ping.** Resolved in F12 as recommended; see "Decisions made".
