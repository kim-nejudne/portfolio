# PLINTH

A 16-week periodised strength program, as a single static marketing page.
Spoke 2 of [kimnejudne.dev](https://kimnejudne.dev) — the animation showcase.

**Live:** https://plinth.kimnejudne.dev

Kinetic editorial: bone, ink, and two saturated colours with a semantic job —
blue is the plan, vermilion is the effort. No photographs anywhere; every visual
is type, colour, hairline rule or drawn SVG. Nine full-bleed plates, scroll-
choreographed with GSAP.

```
frontend/     the app — Vite + React 19 + TypeScript + Tailwind 4 + GSAP
  src/        components split one per plate, plus data.ts and gsapSetup.ts
  scripts/    brand.sh — regenerates the share card and icons from HTML
deploy/       deploy.sh, the nginx vhost, and the droplet runbook
```

## Working on it

```bash
cd frontend
npm install
npm run dev        # localhost:3000
npm run typecheck
npm run build      # typechecks, then builds to frontend/dist
```

## Origin, stated plainly

The first draft of this page was generated by an AI app builder from a written
brief (`../block-scaffold-prompt.md`). That scaffold is the starting line, not
the deliverable — see `CASE-STUDY.md` for what it shipped, what it got wrong
against its own definition of done, and what the craft pass changed.

Its predecessor — a different PLINTH, a gym marketing site — is preserved on
branch `recovered/plinth-craft-pass` and tag `recovery/plinth-2026-07-31`.

## Deploying

See `deploy/README.md`. Static files on a DigitalOcean droplet behind nginx —
